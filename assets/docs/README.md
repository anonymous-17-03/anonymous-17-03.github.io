# Currículum en PDF

Coloca aquí el CV definitivo con el nombre exacto `victor-garcia-cv.pdf`.

La página `/cv/` lo detecta, verifica que sea un PDF y activa el visor, el enlace para abrirlo y la descarga. No necesitas modificar el HTML ni el JavaScript. El archivo será público cuando lo subas al repositorio y publiques GitHub Pages.

Mientras no exista ese PDF, se mantiene el enlace al currículum actual de Canva. No se incluye un documento de ejemplo para evitar que se confunda con tu CV real.
